# Patrick work samples

Public, intentionally narrow work-in-progress shelf for specific artifacts and bounded feedback.

This repository is not a business plan, customer database, private operating log, or complete record of any experiment. It contains only the CTF Grid visual work samples and the questions used to review them.

## Current sample

Open `ctf-grid-review/review.html` for the side-by-side comparison.

The review asks:

- which option is clearest at normal video size;
- whether both axes and low-to-high directions are legible;
- whether the graphic maps trip demands rather than rates a traveler;
- what single change should be made next.

## Feedback rule

Feedback should identify an option, a reason, and one requested change. A selection without a reason is not treated as a durable preference.

## Boundary

Included: visual artifacts, rendered previews, review questions.

Excluded: private business plans, customer or participant data, inbox content, credentials, raw workflow reports, financial information, and personal health information.

This is a work-in-progress artifact shelf. It does not claim cold-audience comprehension, market demand, workshop success, or clinical effectiveness.
